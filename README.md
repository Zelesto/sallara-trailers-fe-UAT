# Trailer Fleet Management Frontend

This is the frontend for the trailer fleet management system.

## Local development

- Install dependencies: `npm install`
- Run the app: `npm run dev`
- Build for production: `npm run build`

## Deployment notes

- The app is configured to talk to the Render backend service by default.
- Override the API target with `VITE_API_BASE_URL` for local or staging environments.
